# Documentación del Proyecto PolyLiquidity

Esta carpeta contiene toda la documentación del proyecto organizada en tres categorías principales:

## 📁 Estructura de Carpetas

### ✅ DONE/
Documentación de componentes y funcionalidades que ya están **completamente implementadas y finalizadas**.

**Contenido:**
- Especificaciones técnicas de servicios implementados
- Documentación de integraciones completadas
- Análisis de APIs finalizados
- Estado actual del backend

### ⏳ PENDING/
Documentación de tareas, planes o funcionalidades que están **pendientes de implementación o completar**.

**Contenido:**
- Planes de refactorización
- Endpoints o funcionalidades pendientes
- Mejoras futuras documentadas

### 📚 GENERAL_EXPLANATIONS/
Documentación de carácter general que explica conceptos, arquitectura general, guías de inicio y resúmenes ejecutivos.

**Contenido:**
- Explicaciones generales de la arquitectura
- Teoría de estrategias
- Guías de inicio
- Resúmenes ejecutivos
- Validaciones y reglas

---

## 📖 Cómo Usar Esta Documentación

1. **Para entender la arquitectura completa:** Revisa `GENERAL_EXPLANATIONS/overall.md` y `GENERAL_EXPLANATIONS/Executive_Summary.md`

2. **Para ver qué está implementado:** Revisa los documentos en `DONE/`

3. **Para ver qué falta por hacer:** Revisa los documentos en `PENDING/`

4. **Para entender conceptos específicos:** Busca en `GENERAL_EXPLANATIONS/` o en los documentos de servicios en `DONE/`

---

## 🔄 Mantenimiento

Cuando un documento en `PENDING/` se complete, debe moverse a `DONE/`.

Cuando se agregue nueva documentación:
- Si es sobre algo implementado → `DONE/`
- Si es sobre algo pendiente → `PENDING/`
- Si es explicación general → `GENERAL_EXPLANATIONS/`
