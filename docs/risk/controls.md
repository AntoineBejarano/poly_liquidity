# Risk Controls

**Purpose**: Technical specification for risk engine controls, exposure management, and order validation.

**Audience**: Engineers implementing risk controls, risk managers, operations team.

**Where this is used**: Risk engine, order validation, exposure tracking.

**Last updated**: 2025-01-XX

---

## Overview

The Risk Engine controls **ALL operational and financial risk** associated with automated trading on Polymarket.

**Key Functions:**

1. **Validate each Order Intent** generated by Strategy Engine
2. **Allow safe operations** and block those exceeding parameters
3. **Maintain updated state** of:
   - Exposure per market
   - Global exposure
   - Active markets
   - Open and pending orders
   - Latency and system health state

**The Risk Engine is the final barrier** before sending real orders to blockchain.

## Order Validation

### Input: OrderIntent

```python
class OrderIntent:
    market_id: UUID
    side: str = "BUY"
    price: float
    size: float  # In shares
    reason: str
    metadata: Dict = {}
```

### Validation Checks

1. **Market Exposure Check**
   - Current exposure + new order size <= `max_market_exposure`
   - Default: 10,000 USDC per market

2. **Global Exposure Check**
   - Current global exposure + new order size <= `max_global_exposure`
   - Default: 200,000 USDC total

3. **Active Markets Check**
   - Number of active markets + 1 <= `max_markets_active`
   - Default: 10 markets

4. **Order Size Check**
   - `min_order_size` <= size <= `max_order_size`
   - Default: 100 - 5,000 USDC

5. **Latency Check**
   - If `latency_status == RED`: Reject
   - If `latency_status == YELLOW`: Reduce size

6. **System Health Check**
   - If `system_active == False`: Reject
   - If circuit breakers open: Reject

### Output: ApprovedOrderIntent

```python
class ApprovedOrderIntent:
    market_id: UUID
    side: str
    price: float
    size: float  # May be adjusted
    original_size: float
    adjustments: Dict  # Applied adjustments
```

## Exposure Management

### Exposure Calculation

**Method: `notional`** (default)
- Exposure = order size × price
- Simple and direct

**Method: `capital_at_risk`**
- Exposure = order size × (1 - price)
- Accounts for probability

**Method: `weighted`**
- Exposure = order size × price × weight_factor
- Custom weighting

### Exposure Tracking

**Per Market:**
```python
market_exposure: Dict[UUID, float] = {
    "market_1": 4000.0,
    "market_2": 7000.0
}
```

**Global:**
```python
global_exposure: float = 11000.0
```

**Active Markets:**
```python
active_markets: Set[UUID] = {"market_1", "market_2", "market_3"}
```

### Exposure Updates

**On Order Intent Approval:**
- Add to market exposure
- Add to global exposure
- Add to active markets

**On Order Fill:**
- Update exposure with actual fill
- Adjust for partial fills

**On Order Cancellation:**
- Remove from pending exposure
- Update active markets

## Size Adjustments

### Latency-Based Adjustments

**YELLOW Mode:**
- Reduce size by 50%
- Apply conservative sizing

**RED Mode:**
- Reject all orders
- Cancel open orders

### Exposure-Based Adjustments

**If approaching limit:**
- Reduce size proportionally
- Ensure limit not exceeded

**If limit exceeded:**
- Reject order
- Log violation

---

## Fail-Safe Mechanisms

### Automatic Rejection

**Conditions:**
- Exposure limits exceeded
- System in RED mode
- Circuit breakers open
- Invalid order parameters

**Action:**
- Reject OrderIntent
- Log rejection reason
- Notify Strategy Engine

### Emergency Stop

**Conditions:**
- Manual kill switch activated
- Critical system error
- Security breach detected

**Action:**
- Reject all new intents
- Cancel open orders
- Alert operators

## Configuration

```python
class RiskConfig:
    max_market_exposure: float = 10000.0
    max_global_exposure: float = 200000.0
    max_markets_active: int = 10
    max_order_size: float = 5000.0
    min_order_size: float = 100.0
    latency_fail_mode: str = "strict"  # "strict" | "lenient"
    reduce_size_in_yellow: bool = True
    cancel_on_red: bool = True
    exposure_method: str = "notional"  # "notional" | "capital_at_risk" | "weighted"
```
